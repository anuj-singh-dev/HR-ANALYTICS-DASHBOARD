# 📊 HR Analytics Dashboard

A complete HR Analytics project built using Python to analyze employee attrition and generate meaningful business insights through data visualization.

---

## 📌 Project Overview

Employee attrition is one of the major challenges faced by organizations. This project analyzes employee data to identify the key factors influencing employee turnover and helps HR teams make data-driven decisions.

The dashboard provides interactive visualizations and statistical insights into employee demographics, salary, departments, job roles, overtime, work-life balance, and job satisfaction.

---

## 🎯 Objectives

- Analyze employee attrition trends.
- Identify factors affecting employee turnover.
- Perform exploratory data analysis (EDA).
- Generate insightful visualizations.
- Build a professional HR Analytics Dashboard.
- Help organizations improve employee retention.

## 💡 Key Business Insights

- Employees working overtime have a higher attrition rate.
- Certain departments experience greater employee turnover.
- Lower monthly income is associated with increased attrition.
- Work-life balance significantly impacts employee retention.
- Job satisfaction plays an important role in reducing attrition.
- HR teams can use these insights to improve employee retention strategies.
